# Project Title: GPX Data Visualizer

This project aims to create an application or tool to generate visualizations from GPX data captured via mobile devices.

## Structure

- `src/`: Contains the main source code for the application.
- `data/`: Stores GPX data. Raw GPX files should be placed in `data/raw/`.
- `docs/`: Project documentation.
- `tests/`: Unit tests for the project.
- `notebooks/`: Jupyter notebooks for data exploration and analysis.
- `scripts/`: Utility scripts.
